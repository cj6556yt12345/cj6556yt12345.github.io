archX

A fast, sleek, and highly optimized Linux distribution powered by Arch Linux and the lightweight XFCE4 desktop environment.

Out-of-the-Box Features

  • Optimized Kernel: Tuned for maximum stability and daily driving.
  • Gaming and Media Ready: Steam, Discord, VLC Player, and GIMP come pre-installed.
  • Modern Audio Stack: Advanced sound handling driven by modern Pipewire and Wireplumber architectures.
  • Developer Friendly: Python 3 environment and pip manager ready instantly.
  • Clean Custom Visuals: Gorgeous dark interface themed matching your hardware styling rules.

System Requirements

  • Processor: 64-bit dual-core CPU or better
  • Memory: 2 GB of RAM minimum (4 GB recommended)
  • Storage: 15 GB of free hard drive space
  • Graphics: Intel, AMD, or NVIDIA graphics card

Installation Instructions

  1. Download the official ArchX ISO file using the button above.
  2. Flash the file to a USB flash drive using a tool like Rufus (DD Image mode is recommended).
  3. Power off your target computer, insert the USB drive, and boot using your system boot menu key (F12, F11, or F8).
  4. Select the live boot installer environment from the screen menu.
